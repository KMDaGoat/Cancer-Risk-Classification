# Cancer-Risk-Classification
Simple Beginner Project 
-used logistic regression as it returns a probability which can be used as a way to output the probability of someone having cancer
-used accuracy to get a rough estimate of the quality of the model 
-used two data sets and combined the z values to get an overall risk value over the combination of different features
-used different datasets to cover various amounts of different features such as clinical , environmental and symptomatic features
-used matplotlib to output the a graph the overall risk percentage in respect to the combined risk score
